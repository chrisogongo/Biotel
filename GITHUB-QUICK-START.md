## 🎯 Quick Start (5 Minutes)

### Step 1: Initialize Git Repository

Open your terminal in the project directory and run:

```bash
# Initialize Git
git init

# Add all files
git add .

# Create first commit
git commit -m "Initial commit: Biotel DNA website with AI chatbot and SEO optimization"
```

### Step 2: Create GitHub Repository

1. Go to **https://github.com/new**
2. Fill in:
   - **Repository name**: `biotel-dna-website`
   - **Description**: `Professional DNA Testing Services Website for Biotel DNA Kenya`
   - **Public** or **Private** (your choice)
   - ❌ **Do NOT** initialize with README, .gitignore, or license
3. Click **Create repository**

### Step 3: Connect and Push

Copy and run these commands (replace `YOUR_USERNAME` with your GitHub username):

```bash
# Add GitHub as remote
git remote add origin https://github.com/YOUR_USERNAME/biotel-dna-website.git

# Rename branch to main
git branch -M main

# Push to GitHub
git push -u origin main
```

**🎉 That's it! Your code is now on GitHub!**

## 🚀 Deploy Your Website

### Option 1: Vercel (Recommended - Easiest)

1. Go to **https://vercel.com/signup**
2. Sign up with GitHub
3. Click "Import Project"
4. Select your `biotel-dna-website` repository
5. Click "Deploy"
6. Done! Your site is live in 2-3 minutes

**Build Settings:**
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`

### Option 2: Netlify

1. Go to **https://www.netlify.com/**
2. Sign up with GitHub
3. Click "Add new site" → "Import an existing project"
4. Select your repository
5. Set build command: `npm run build`
6. Set publish directory: `dist`
7. Click "Deploy site"

### Option 3: GitHub Pages

```bash
# Install gh-pages
npm install --save-dev gh-pages

# Add to package.json scripts:
# "predeploy": "npm run build",
# "deploy": "gh-pages -d dist"

# Deploy
npm run deploy
```

Then enable GitHub Pages in repository Settings → Pages
