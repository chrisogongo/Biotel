🚀 How to Download & Deploy

  1. Open your terminal and navigate to your project folder
  2. Build the project:
    npm run build
  3. Create a ZIP file:
    # Windows (PowerShell)
    Compress-Archive -Path dist\* -DestinationPath bioteldna-website.zip

    # Mac/Linux
    cd dist && zip -r ../bioteldna-website.zip . && cd ..
  4. Upload to cPanel:
    • Login to cPanel
    • Open File Manager
    • Navigate to public_html
    • Upload bioteldna-website.zip
    • Extract the ZIP file
    • Delete the ZIP file
  5. Test your website at your domain

💡 Alternative Methods

Method 1: View Files in Browser

After building, you can view the files in your browser:

Method 2: Use File Transfer

If you have SSH/SFTP access to your hosting:

# Using SCP (Secure Copy)
scp -r dist/* username@yourdomain.com:/public_html/

# Using rsync
rsync -avz dist/ username@yourdomain.com:/public_html/

Method 3: Deploy via Git

If your hosting supports Git deployment:

# Add dist to git
git add dist/
git commit -m "Production build"
git push origin main
