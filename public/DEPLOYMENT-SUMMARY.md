## 🚀 Quick Deployment (10 Minutes)

### Step 1: Build Your Website
```bash
npm run build
```
**Result:** Creates `dist/` folder with production files

### Step 2: Create ZIP File
```bash
# Windows (PowerShell)
Compress-Archive -Path dist\* -DestinationPath bioteldna-website.zip

# Mac/Linux
cd dist && zip -r ../bioteldna-website.zip . && cd ..
```

### Step 3: Upload to cPanel
1. Login to cPanel
2. Open File Manager
3. Navigate to `public_html`
4. Upload `bioteldna-website.zip`
5. Extract ZIP file
6. Delete ZIP file

### Step 4: Test Your Site
Visit: `https://yourdomain.com`

**✅ That's it! Your website is live!**
