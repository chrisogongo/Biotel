# 📥 Download Guide - Biotel DNA Kenya Website

## ⚠️ Important Information

The `dist/` folder contains the **production-ready build** of your Biotel DNA Kenya website. However, since this is a **web-based development environment**, you cannot directly download files from here.

## ✅ How to Get Your Files

### Option 1: Build Locally (RECOMMENDED)

If you have access to the source code on your computer:

```bash
# 1. Navigate to your project folder
cd biotel-dna-website

# 2. Install dependencies (if not already done)
npm install

# 3. Build the production version
npm run build

# 4. Your dist/ folder is now ready!
# 5. Create a ZIP file for easy deployment
```

**Create ZIP Archive:**

**Windows (PowerShell):**
```powershell
Compress-Archive -Path dist\* -DestinationPath bioteldna-website.zip
```

**Mac/Linux:**
```bash
cd dist && zip -r ../bioteldna-website.zip . && cd ..
```

### Option 2: Access Files via Preview URL

Since the website is built and deployed in this environment, you can:

1. **View the live website** at the preview URL provided by this platform
2. **Access the download instructions page** at: `/download-instructions.html`
3. **View individual files** at: `/download.html`

### Option 3: Copy Files Manually

If you need specific files, you can:
